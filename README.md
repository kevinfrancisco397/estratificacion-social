## Publicar la página web completa

1. Descarga el archivo de la versión completa (se encuentra en la conversación con Grok).
2. Renómbralo a `index.html`.
3. En este repositorio haz clic en **Add file → Upload files** y sube el `index.html`.
4. Ve a **Settings → Pages** (en el menú izquierdo).
5. En **Build and deployment → Source** elige **Deploy from a branch**.
6. Branch: `main`  ·  Folder: `/ (root)`  ·  Guarda.
7. Espera 1-2 minutos. Tu presentación estará publicada en:

### 👉 https://kevinfrancisco397.github.io/estratificacion-social/
